# Интеграционные тесты DSL

Тестовое приложение принимает JSON через FastAPI, разбирает DSL средствами
Pydantic и выполняет выражение производственного SQLAlchemy-компилятора в SQLite.
Для каждого теста создаётся отдельная база в памяти с четырьмя заявками; порядок
результатов фиксирован по `id`. API возвращает заявки целиком, а тесты проверяют
состав и содержимое ответа. Проверяются операторы, вложенные группы,
отрицание, поиск, whitelist и некорректные запросы.

Это интеграционные тесты: они проверяют взаимодействие нескольких компонентов
с настоящей базой. SQLite использует стандартный драйвер Python; дополнительных
зависимостей не нужно. Установите существующий extra проекта `sqlalchemy` и
запустите из корня:

```sh
uv run --group test --extra sqlalchemy pytest tests/integration/dsl -v
```

При отсутствии SQLAlchemy тесты DSL пропускаются при запуске pytest.
Приложение специально использует синхронную SQLite-сессию: оно проверяет
компилятор, но не асинхронный `SqlAlchemyRepository`, пагинацию или сортировку.
Тестовый поиск по заголовку демонстрирует передачу callback, а не PostgreSQL
Full-Text Search. SQLite не заменяет тестирование PostgreSQL: семантика LIKE,
типы, транзакции и возможности конкретной СУБД могут различаться.
